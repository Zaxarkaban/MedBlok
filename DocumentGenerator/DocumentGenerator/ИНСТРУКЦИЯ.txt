  МЕДДОК ГЕНЕРАТОР — ИНСТРУКЦИЯ ДЛЯ ПОЛЬЗОВАТЕЛЯ
================================================================================

Версия: portable для Windows 7 SP1 / 10 / 11 (x64)
Установка .NET не требуется (runtime внутри папки).

Требования для Windows 7:
  • Windows 7 SP1 x64 с обновлениями
  • Visual C++ 2015–2019 Redistributable (x64)
    https://aka.ms/vs/17/release/vc_redist.x64.exe


--------------------------------------------------------------------------------
1. БЫСТРЫЙ СТАРТ
--------------------------------------------------------------------------------

1) Распакуйте архив в любую папку (например, D:\МедДок или на рабочий стол).
2) Запустите файл DocumentGenerator.exe.
3) Откроется главное меню с разделами программы.

ВАЖНО: не удаляйте и не переносите отдельно от .exe файлы:
   • Template.pdf
   • карта водительская комиссия.pdf
   • папку Fonts\
   • папку DoctorForms\
   • папку ExtraForms\
Они должны лежать в той же папке, что и DocumentGenerator.exe.

Настройки (тема оформления, пути) сохраняются в:
   %AppData%\DocumentGenerator\


--------------------------------------------------------------------------------
2. ГЛАВНОЕ МЕНЮ
--------------------------------------------------------------------------------

  Профосмотры              — основная форма и пакетная выгрузка из Excel
  Водительская комиссия    — отдельная форма для медсправки водителя
  Расчёт КП                — расчёт контингент-плана (врачи и исследования)
  Конструктор              — создание своих форм и шаблонов
  Пользовательские приложения — список созданных вами программ
  Выход                    — закрыть программу

Кнопка ⚙ (шестерёнка) — выбор темы оформления:
  • Базовая (тёмная)
  • Светлая
  • Космическая


--------------------------------------------------------------------------------
3. ПРОФОСМОТРЫ — ОДИН ДОКУМЕНТ
--------------------------------------------------------------------------------

Путь: Главное меню → «Профосмотры»

1) Заполните поля формы:
   — поликлиническое отделение, ФИО, должность, дата рождения, пол;
   — пункты вредности (можно выбрать несколько: Ctrl + левый клик);
   — СНИЛС, паспорт, адрес, телефон, полис, место работы и др.

2) Красный текст под полем — подсказка об ошибке. Исправьте данные
   перед сохранением.

3) «Предпросмотр» — посмотреть PDF до сохранения.
4) «Сохранить» — выбрать папку и сохранить готовый PDF.

Программа автоматически подставит:
   • список врачей по выбранным пунктам вредности;
   • список исследований с учётом возраста и пола.


--------------------------------------------------------------------------------
4. ПРОФОСМОТРЫ — ПАКЕТНАЯ ВЫГРУЗКА ИЗ EXCEL
--------------------------------------------------------------------------------

Путь: Главное меню → «Профосмотры» → кнопка «Загрузить Excel»

1) Выберите файл Excel (.xlsx или .xls).
2) Выберите папку, куда сохранить PDF.
3) Дождитесь окончания — для каждой строки таблицы создаётся отдельный PDF
   (имя файла — по ФИО сотрудника).
4) В той же папке появится Statistics.xlsx — сводная статистика
   по врачам и исследованиям.

Структура Excel (первый лист):
   • Строка 1 — шапка организации (место работы, адрес, ОКВЭД и т.д.)
   • Строка 2 — заголовки столбцов
   • Со строки 3 — данные сотрудников

Основные столбцы (по порядку):
   B — ФИО
   C — должность
   D — подразделение
   E — дата рождения (ДД.ММ.ГГГГ или дата Excel)
   G — пол (М / Ж)
   H — пункты вредности
   I — СНИЛС
   J — полис ОМС
   K–N — паспорт (серия, номер, дата, кем выдан)
   O — телефон
   P — адрес
   Q — стаж (лет)

Пустые строки и строки без ФИО пропускаются автоматически.

Совет: на рабочем столе может лежать файл «Шаблон_МедДок_копировать-вставить.txt»
       — удобный образец для подготовки данных.


--------------------------------------------------------------------------------
5. ВОДИТЕЛЬСКАЯ КОМИССИЯ
--------------------------------------------------------------------------------

Путь: Главное меню → «Водительская комиссия»

1) Заполните поля формы.
2) «Предпросмотр» — проверить результат.
3) «Сохранить» — сохранить PDF в выбранную папку.

Шаблон: «карта водительская комиссия.pdf» (лежит рядом с .exe).


--------------------------------------------------------------------------------
6. РАСЧЁТ КП (КОНТИНГЕНТ-ПЛАН)
--------------------------------------------------------------------------------

Путь: Главное меню → «Расчёт КП»

Назначение: подсчёт, сколько раз каждый врач и каждое исследование
встречаются в выбранном контингенте.

1) Отметьте пункты вредности в списке (Ctrl + клик для нескольких).
2) Укажите численность по группам (мужчины/женщины, до 40 / старше 40).
3) Нажмите кнопку расчёта — внизу появится результат.
4) При необходимости экспортируйте отчёт в Excel.


--------------------------------------------------------------------------------
7. КОНСТРУКТОР — СВОИ ФОРМЫ
--------------------------------------------------------------------------------

Путь: Главное меню → «Конструктор»

Позволяет создать свою «программу»: PDF-шаблон + набор полей.

Шаги:
1) Введите название программы.
2) Нажмите «Выбрать» и укажите PDF-шаблон с полями формы (AcroForm).
3) Слева — палитра блоков (Текст, Число, Дата, Список, Флажок и т.д.).
   Перетащите нужный блок в центральную область «Форма».
4) Выделите поле — справа задайте свойства:
   • название блока;
   • подпись для пользователя;
   • имя поля в PDF (должно совпадать с именем в шаблоне);
   • обязательность, варианты для списков.
5) «Опубликовать» — сохранить программу в список пользовательских.

ПКМ по полю в форме → Дублировать / Удалить.


--------------------------------------------------------------------------------
8. ПОЛЬЗОВАТЕЛЬСКИЕ ПРИЛОЖЕНИЯ
--------------------------------------------------------------------------------

Путь: Главное меню → «Пользовательские приложения»

  Создать      — новая программа в конструкторе
  Открыть      — заполнить и сохранить PDF по выбранной программе
  Редактировать — изменить существующую программу
  Экспорт      — сохранить программу в файл (перенос на другой ПК)
  Импорт       — загрузить программу из файла
  Удалить      — удалить из списка


--------------------------------------------------------------------------------
9. ЧАСТЫЕ ВОПРОСЫ
--------------------------------------------------------------------------------

В: Программа не запускается.
О: Запускайте DocumentGenerator.exe из папки, куда распакован архив.
   Антивирус иногда блокирует portable-приложения — добавьте папку в исключения.

В: PDF пустой или поля не заполнились.
О: Проверьте, что Template.pdf лежит рядом с .exe и не повреждён.
   В конструкторе — что имя поля PDF совпадает с именем в шаблоне.

В: Excel не загружается.
О: Формат .xlsx / .xls. Первая строка данных — не пустая. ФИО в столбце B.
   Дата рождения — корректная (ДД.ММ.ГГГГ).

В: Куда сохраняются мои программы?
О: В %AppData%\DocumentGenerator\ (папка user-programs).

В: Можно ли работать без интернета?
О: Да. Интернет нужен только при первом скачивании/обновлении архива.
